## 🚀 The Pitch: Agentic AI via Vibe Coding

Traditional deepfake detection relies on "black-box" classifiers that spit out a confidence score with zero explanation. **MediaSense** represents a paradigm shift. 

Built entirely via **Vibe Coding**, MediaSense is an **Agentic AI** that utilizes the native multimodal capabilities of **Google Gemini 1.5 Flash**. Instead of passively classifying pixels, our agent actively *reasons* through the media. It visually inspects the data for spatial noise, anatomical anomalies, and lighting inconsistencies, generating an **Explainable AI (XAI)** forensic report alongside its confidence score. 

We bring transparency and trust back to digital media.

## 🏗️ The Architecture

MediaSense is built on a highly scalable, decoupled, and containerized microservices architecture optimized for low-latency inference.

*   🧠 **AI Engine:** Google Gemini 1.5 Flash (Native Multimodal)
*   ⚙️ **Backend:** Python / FastAPI (High Concurrency)
*   ☁️ **Deployment:** Google Cloud Run (Serverless, Dockerized)
*   🎨 **Frontend:** React / Vite / TailwindCSS (Premium Glassmorphism UI)

---

## 🕵️‍♂️ The Agentic Workflow

1.  **Media Ingestion:** The user uploads an image or video via the highly responsive React frontend.
2.  **Agent Prompting:** The file is securely transmitted to the FastAPI backend, where it is bundled with a highly optimized, zero-shot system prompt.
3.  **Multimodal Reasoning:** The Gemini 1.5 Flash model processes the image and prompt concurrently, actively looking for specific AI generation artifacts (e.g., asymmetric pupils, distorted fingers, impossible lighting).
4.  **Schema Enforcement:** The backend enforces a strict JSON schema parsing on the Gemini output to guarantee structured communication.
5.  **XAI Reporting:** The frontend elegantly surfaces the classification, the mathematically mapped confidence score, and the human-readable Forensic Report generated by the Agent.

## 💻 Setup Instructions

Want to run the Agent locally? Follow these steps:

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/Image-Sense.git
cd Image-Sense
```

### 2. Configure the Backend
Navigate to the backend directory and install the Python dependencies.

```bash
cd backend
python -m venv venv
source venv/bin/activate  # On Windows use `venv\Scripts\activate`
pip install -r requirements.txt
```

Set your Google Gemini API Key:
```bash
# On Mac/Linux
export GEMINI_API_KEY="your_api_key_here"

# On Windows (PowerShell)
$env:GEMINI_API_KEY="your_api_key_here"
```

Start the FastAPI server:
```bash
uvicorn main:app --host 0.0.0.0 --port 8080 --reload
```

### 3. Configure the Frontend
Open a new terminal window, navigate to the root directory, install dependencies, and start the Vite development server.

```bash
# From the root Image-Sense directory
npm install
npm run dev
```

Visit `http://localhost:5173` to interact with the MediaSense Agent!
